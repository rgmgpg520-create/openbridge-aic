# 本地模型安装与许可

## 模型

- 名称：Qwen3-VL-2B-Instruct
- 来源：https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct
- 本地目录：`D:\qwen\Qwen\Qwen3-VL-2B-Instruct`
- 模型卡声明：Apache-2.0；提交前以官方模型仓库当前许可、使用政策和权重条款为准。

## 安装

在 `D:\OpenBridge_AIC` 执行。推荐使用项目内 Python 3.11 虚拟环境：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r model\requirements.txt
```

如使用 CPU 或其他 CUDA 版本，应按本机硬件和 PyTorch 官方安装说明替换第一条安装命令。运行依赖体积较大，模型启动时间和吞吐量取决于硬件。

如无法使用预装模型，可从官方模型仓库获取权重，不能把权重放入参赛成果链接，除非确认许可允许再分发。启动：

```powershell
.\.venv\Scripts\python.exe model\serve.py
```

## 作品中的自主实现

Qwen 负责根据证据组织自然语言；团队自主实现固定版本索引、证据检索、提示词约束、来源绑定、风险护栏、Issue 草稿、评测和网页工作台。模型输出不被直接当作事实，页面始终显示来源和人工确认边界。

## 验证要求

只有当 `/api/status` 返回 `online: true` 且问答轨迹显示“开源模型生成”时，才能把演示记录写成模型已运行。否则必须记录“规则降级：模型未启动”，不得填报 AI 生成准确率。
