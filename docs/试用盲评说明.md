# OpenBridge 用户试用与 A/B 盲评说明

本文件用于补齐技术报告"成果展示与效果验证"中的**用户试用反馈**维度：在机器指标（召回率、词项覆盖、逐句核验）之外，让真实用户在**不知道回答来自哪个系统**的情况下，比较"通用模型单独作答"与"OpenBridge（检索+模型+核验）"两类回答，形成可复现的用户偏好数据。

## 一、试用对象与人数

- 建议 3–5 名试用者，覆盖三种熟悉度：1=没用过 Requests/HTTP 库、2=用过、3=熟悉。
- 每人在**同一台电脑、同一套固定快照**下独立完成，不互相讨论答案；评审前不知道 A/B 分别对应哪个系统。
- 每位试用者使用不同代号（如 student01、student02），记录匿名、可追溯。

## 二、盲评流程（每人约 10 分钟）

前置：**不需要模型、不需要启动服务器、不需要显卡**。盲评脚本只读取 `results/latest-results.json` 中已冻结的 12 组回答，纯 Node 运行；只需 Node.js 18+ 与仓库内的 `scripts/ab-blind-review.mjs`、`results/latest-results.json` 两个文件。

对外分发请直接使用 `dist/OpenBridge_试用包.zip`（含说明、反馈表、一键启动脚本），组织流程见 `docs/试用组织指南.md`。

```powershell
cd D:\OpenBridge_AIC
node scripts/ab-blind-review.mjs
```

按提示操作：

1. 输入评审员代号和熟悉程度（1/2/3）。
2. 每题会看到同一问题的【回答 A】和【回答 B】，顺序由代号和题号随机决定。
3. 每题回答三个问题：
   - 整体更准确、更有用的是 A / B / 平手（`=`），不了解可跳过（`s`）；
   - 给 A、B 分别打正确性分（1–5，5 最高）；
   - 可写一句判断理由（可留空）。
4. 全部答完后，屏幕才揭晓 A/B 对应关系；结果自动保存到 `results/ab-reviews/<代号>.json`。

中途可按 Ctrl+C 退出，已答内容仍会保存。

## 三、汇总

所有试用者完成后，负责人运行：

```powershell
node scripts/ab-blind-review.mjs --summary
```

产出 `results/ab-summary.json`，包含：参评人数、有效题数、OpenBridge 胜/负/平手比例、双方平均正确性分、逐题偏好分布。该文件与 `results/ab-reviews/` 一并随仓库公开，作为用户 A/B 测试证据。
