# OpenBridge 使用说明

> 本文件是**入口**：怎么启动、路径不对怎么办、报错查表。
> 安装细节、评测命令、异常处理在完整版：`..\docs\运行说明.md`。

## 一、30 秒启动

| 想做什么 | 双击什么 |
| --- | --- |
| 完整演示（网页 + 本地 Qwen 模型） | `启动.bat` |
| 只看界面（不加载模型，最快） | `启动-仅网页.bat` |
| 先确认这台电脑能不能跑 | `诊断.bat` |
| 什么都不装，只看回放 | `..\dist\OpenBridge-离线演示.html` |

启动成功后浏览器自动打开 `http://127.0.0.1:4173`：

- 右上角 **「本地 Qwen 模型在线」** = 模型已接通，可以真实问答；
- 右上角 **「规则降级」** = 网页可用、证据浏览器可用，但模型没起来，原因会打印在启动窗口里。

硬性依赖只有 **Node.js 18+**（`node -v` 能看到版本号即可）。模型的 Python、PyTorch 和权重不随包分发。

## 二、路径不同怎么办

- 脚本以「自己所在文件夹的**上一级**」为项目根目录（`%~dp0..`，`start-openbridge.ps1` 逐级向上查找 `server.mjs`），所以换盘符、中文路径、带空格、U 盘、OneDrive 目录都能直接双击。
- 前提只有一个：**`使用说明\` 要留在项目里**（与 `server.mjs` 同层）。单独把这个文件夹拷走，会提示「定位项目目录失败」。
- 自动探测找不到时，设好环境变量后仍然双击 `启动.bat`：

| 变量 | 作用 | 示例 |
| --- | --- | --- |
| `OPENBRIDGE_PYTHON` | 指定带 torch 的 Python | `$env:OPENBRIDGE_PYTHON='E:\envs\torch\python.exe'` |
| `OPENBRIDGE_MODEL_DIR` | 指定 Qwen 权重目录 | `$env:OPENBRIDGE_MODEL_DIR='E:\models\Qwen3-VL-2B-Instruct'` |
| `OPENBRIDGE_MODEL_URL` | 连别的推理服务 | `$env:OPENBRIDGE_MODEL_URL='http://127.0.0.1:9000'` |
| `OPENBRIDGE_MODEL_LABEL` | 外接别的服务时标注实际模型名（默认 Qwen3-VL-2B-Instruct） | `$env:OPENBRIDGE_MODEL_LABEL='deepseek-chat'` |
| `OPENBRIDGE_MODEL_LICENSE` | 该后端的许可证声明（默认 Apache-2.0） | `$env:OPENBRIDGE_MODEL_LICENSE='服务条款'` |
| `PORT` | 改网页端口（4173 被占用时） | `$env:PORT='5000'` |
| `MODEL_PORT` | 改模型端口（8080 被占用时） | `$env:MODEL_PORT='9000'` |

Node / Python / 权重三者的自动探测顺序见 `..\docs\运行说明.md` 第 4 节。

## 三、常见提示

| 屏幕上的话 | 含义 | 怎么办 |
| --- | --- | --- |
| 没有找到 Node.js | 没装或没进 PATH | 装 Node 18+ 后重新双击 `启动.bat` |
| 没有找到 Qwen3-VL-2B-Instruct 权重目录 | 权重不在默认位置 | 用 `OPENBRIDGE_MODEL_DIR` 指过去 |
| 没有找到带 torch + transformers 的 Python | Python 环境不对 | 用 `OPENBRIDGE_PYTHON` 指定，或按完整版第 3 节建环境 |
| 端口 4173 已被其它程序占用 | 端口冲突 | 关掉占用程序，或 `$env:PORT='5000'` |
| 规则降级：模型未启动 | 网页在跑、模型没跑 | 界面可看；真实模型演示要模型在线 |
| 模型服务已就绪 | 一切正常 | 右上角出现「本地 Qwen 模型在线」后开始提问 |
| 定位项目目录失败：找不到 server.mjs | `使用说明` 被单独拷走 | 放回项目里，或先 cd 到项目根再运行 |
